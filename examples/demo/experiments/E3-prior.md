# 加入平滑先验，扫先验强度

## 目的与预测
- 要回答的问题：平滑先验能否把误差降到基线的 80% 以下。
- 预测（跑之前写）：强度 0.2 时误差降到 0.064 以下（比基线低 20%）；强度超过 0.3 后收益消失。
- 判否条件（什么结果会推翻这条预测）：任何强度下降幅度都小于 10%，或强度 0.2 的降幅区间包含 0。
- 对照条目（id）：E1-baseline

## 配置指纹
| 项 | 值 |
|---|---|
| 数据版本 | synth-v1，同 E1 |
| 代码版本 | a1b2c3d |
| 随机种子 | 0–4 |
| 关键超参数 | lr 1e-3，30 轮，先验强度见下 |
| 评测口径 | 同 E1 |

## 逐次记录
| # | 结果 | 备注 |
|---|---|---|
| 1 | 完成 | 强度 0.1，误差 0.074 |
| 2 | 完成 | 强度 0.2，误差 0.069 |
| 3 | 完成 | 强度 0.3，误差 0.071 |
| 4 | 完成 | 强度 0.5，误差 0.088 |

## 结果
- 强度 0.2 时平均误差 0.069，比基线 0.082 低 16%（配对差区间 [11%, 21%]）。
- 强度 0.5 时误差高于基线 7%。

## 判定
- 强度 0.2 时降到 0.064 以下：不成立（0.069，差一点）。
- 强度超过 0.3 后收益消失：成立（0.5 时反而更差）。
- 判否条件没有触发：降幅 16%，区间不含 0。

## 审查
- 只有高斯噪声一种；先验强度是在测试集上选的，没有单独的验证集，0.069 偏乐观。
- 每个强度只跑了 5 个种子，强度之间的差别（0.069 对 0.071）在区间内不可分。
- 基线偏弱的担心没有解决。
